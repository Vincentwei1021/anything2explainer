# 解说词模板：删掉本注释，按 reference/narration-storyboard.md 写。`# CHAPTER n 章名` 分章；一行一句；`|` 只切字幕块（每块中文 ≤16 字 / 英文 ≤48 字符；英文块之间自动补空格）。
# **空行 = 段落分隔**：一段 = 一个镜头（2–4 句），段末画面停 1–1.5 s 再切；段内小句之间不停顿。别一句一段。
# **每个句内块尾一律写「，」**：竖线不送进 TTS，不写标点、声音的换气点就跟字幕块对不上（"字幕翻页了、声音还在上一句"）。
#   「，」送进 TTS 产生约 0.3–0.4 s 真停顿，字幕显示时自动剥掉块尾标点；句末块不加标点。成片因此长约 5%，写稿时预留。
